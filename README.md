# 🚗 CarRentalShop
This is a project created in December 2022.
It is a Python-based car rental management application that simulates a car rental shop with simple functionality for renting and returning cars. The project is designed for learning or demonstration purposes, featuring basic object-oriented programming in Python.

## 📋 Features

This project helps users with:
- User registration and secure login using JWT authentication
- Creating, updating, and retrieving their personalized todo lists
- Validating input data for registration and login
- Protecting routes to ensure only authenticated users can access their data
